# Customer Segmentation using K-Means Clustering

## 📌 Project Overview

Customer Segmentation is an unsupervised machine learning technique used to group customers based on similar characteristics.

This project uses the **K-Means Clustering algorithm** to segment customers based on features such as:

- Gender
- Age
- Annual Income
- Spending Score

The objective is to identify meaningful customer groups that can help understand different customer behaviors and characteristics.

---

## 🎯 Objectives

- Analyze customer data using unsupervised learning.
- Preprocess and scale the dataset.
- Convert categorical data into numerical form.
- Determine the optimal number of clusters using the Elbow Method.
- Apply K-Means Clustering.
- Visualize the resulting customer segments.
- Generate summary statistics for each cluster.
